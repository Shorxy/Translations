# Installing Essentials

Essentials is a plugin that provide essential basic features to minecraft servers. Great plugin to make vanilla servers more enjoyable eg: (tpa,home,etc)

1. Download Essentials from the [Spigot Page](https://www.spigotmc.org/resources/essentialsx.9089/)
2. Log into the [ForestRacks Control Panel](https://panel.forestracks.com).
3. Navigate to your server and click on the `File Manager` tab.
4. Navigate to the `plugins` folder.
5. Click on the `Upload` button and upload the Essentials jar file.
